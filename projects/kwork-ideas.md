# Идеи для будущих кворков

## Расчёт КЕО

**Статус:** идея на проверку реальным заказом.

Не публиковать отдельный кворк сразу. Сначала взять одну небольшую реальную задачу по расчёту коэффициента естественной освещённости (КЕО), полностью пройти расчёт по исходным данным заказчика и проверить результат на практике.

Если расчёт будет принят заказчиком без существенных замечаний, а желательно также пройдёт проверку специалиста/экспертизы, использовать этот кейс как основу для отдельного кворка.

Возможное название будущего кворка:

**«Выполню расчёт КЕО помещения по СП 52.13330»**

Предполагаемый состав услуги:
- расчёт по предоставленным архитектурным решениям;
- одно помещение в базовой услуге;
- расчётная схема и исходные данные;
- определение нормируемого и расчётного КЕО;
- вывод о соответствии;
- дополнительные помещения — отдельной опцией.

Ограничения позиционирования:
- не обещать гарантированное прохождение экспертизы;
- не включать расчёт инсоляции;
- не брать на себя корректность отсутствующих исходных архитектурных данных;
- сначала отработать методику и оценить реальную трудоёмкость.
